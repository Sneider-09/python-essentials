# Python Essentials – Cisco

Repositorio de ejercicios, prácticas y códigos desarrollados durante la serie de cursos **Python Essentials 1 y Python Essentials 2**, ofrecida por Cisco Networking Academy en colaboración con OpenEDG Python Institute.

El objetivo de este repositorio es documentar mi proceso de aprendizaje, reforzar los fundamentos de programación y aplicar los conceptos de Python mediante ejercicios prácticos.

## Cursos

### 1. Python Essentials 1

Introducción a los fundamentos de la programación y al lenguaje Python. Este curso aborda los conceptos esenciales para desarrollar habilidades de pensamiento lógico, analítico y algorítmico.

**Temas y habilidades:**

- Fundamentos de programación con Python.
- Pensamiento analítico y algorítmico.
- Programación procedural.
- Diseño, desarrollo y depuración de scripts.
- Buenas prácticas de programación.
- Resolución de problemas mediante código.

### 2. Python Essentials 2

Profundización en conceptos avanzados de Python, con énfasis en la programación orientada a objetos y el desarrollo de aplicaciones más estructuradas.

**Temas y habilidades:**

- Módulos y paquetes.
- Clases, objetos y métodos.
- Programación orientada a objetos (OOP).
- Herencia y polimorfismo.
- Excepciones.
- Generadores y propiedades.
- Gestión de paquetes con PIP.

Este curso también prepara para la certificación **PCAP – Certified Associate in Python Programming**.
