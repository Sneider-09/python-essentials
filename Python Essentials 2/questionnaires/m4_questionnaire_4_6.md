**Pregunta 1: ¿Cuál es el resultado del siguiente fragmento de código?**
```
import calendar
print(calendar.weekheader(1))
```
- M T W T F S S

**Pregunta 2: ¿Cuál es el resultado del siguiente fragmento de código?**
```
import calendar
 
c = calendar.Calendar()
 
for weekday in c.iterweekdays():
    print(weekday, end=" ")
```
- 0 1 2 3 4 5 6
